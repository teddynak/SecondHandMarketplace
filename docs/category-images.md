# Category image sources

The homepage uses decorative Unsplash photos, not seller listing photos. They do not represent stock, prices or item condition. Source license: https://unsplash.com/license (reviewed 2026-11-10). No competitor images or logos are copied.

- Clothing: https://images.unsplash.com/photo-1441986300917-64674bd600d8
- Electronics: https://images.unsplash.com/photo-1505740420928-5e560c06d30e
- Books: https://images.unsplash.com/photo-1507842217343-583bb7270b66
- Home & Living: https://images.unsplash.com/photo-1507473885765-e6ed057f782c
- Furniture: https://images.unsplash.com/photo-1503602642458-232111445657
- Sports: https://images.unsplash.com/photo-1485965120184-e220f721d03e
- Other: https://images.unsplash.com/photo-1553062407-98eeb64c6a62

Images request 480 × 320 crops at quality 75, are lazy loaded and have fixed aspect ratios. Labels stay outside images. A failed request leaves the existing category icon and working link. External delivery depends on Unsplash availability. These are manually curated URLs, not Unsplash API search integration.

Product photos continue to come only from sellers through MongoDB uploads or HTTPS links. Never substitute category stock photos for a missing product photo.
